    Eingebaute Mods

    Community-Mods

    Programmiere eine Mod und reich sie ein. DynaTheReal prüft sie, erst danach erscheint sie in der Bibliothek.

    Mod-Programmierung: alle Befehle 
    mod.set('speed', 1.5)     // speed 0.2-4, jump 0.5-3, gravity 0-2, reach 1-4, magnet 1-6, maxHp 20-500
mod.set('fly', true)      // fly, godmode, instaBreak, infiniteItems, noFall, noNight, peaceful, nightVision
mod.give('diamond', 3)    // wood wool iron diamond crystal ruby mythril, planks bricks glass cobble dirt sand gravel door torch campfire bed chest bucket apple crystal_apple
mod.heal(10)  mod.hurt(5)  mod.toast('Text')
mod.teleport(x, y, z)  mod.setBlock(x, y, z, 'stone')  // Blocknamen klein: stone, planks, glass, air ...
mod.time('day')  mod.time('night')  mod.weather('clear'|'cloudy'|'rain'|'storm'|'fog')
mod.spawn(2)  mod.clearMobs()

mod.on('start', () => ...)
mod.on('tick', (s) => ...)    // alle 0,25 s: s = {x,y,z,hp,maxHp,day,night,phase,blood,t,weather}
mod.on('break', (e) => ...)   // e = {x,y,z,block}
mod.on('place', (e) => ...)   // e = {x,y,z,block}
mod.on('kill' | 'night' | 'day' | 'death', (e) => ...)

    Server deiner Freunde

    Hochladen macht eine Kopie, deine eigene Welt bleibt. Wer zuerst reinkommt, lässt die Welt laufen; geht er, übernimmt ein anderer. Ist niemand drin, wartet die Welt. Beitreten dürfen Freunde, die der Besitzer hinzugefügt hat.
